# Photo Studio

A free photo editor that runs in any web browser (Safari or Chrome on iPad, iPhone or computer). It removes backgrounds and objects using AI that runs on your own device, with no account and no uploads.

* Open the app: https://msjag416.github.io/photo-studio/ (once GitHub Pages is turned on)
* How it works: [ARCHITECTURE.md](ARCHITECTURE.md), also at https://msjag416.github.io/photo-studio/ARCHITECTURE.html
* The outside-in study and build plan: [docs/REA-SPEC.md](docs/REA-SPEC.md)

Features: remove background, refine edges brush, remove objects, outline, shadow, blur background, enhance, adjust, filters, rounded corners, opacity, nudge, crop, expand, text, layers, undo/redo, save as PNG or JPG, recent projects.
